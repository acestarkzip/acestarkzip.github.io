## 📕 A. Linux 기초 (2026.10.12 Mon)

<a name="notion-heading-40ad9e129df7806ca8bce5081f775626"></a>

### 📃 a. Linux & Ubuntu (리눅스 소개)

- **Linux** : 서버, 클라우드, 로봇 등 다양한 환경에서 사용되는 오픈소스 운영체제 커널
- **Ubuntu** : Linux 커널을 기반으로 만들어진 운영체제 배포판
- **Terminal** : 명령어를 입력하여 시스템을 제어하는 인터페이스

<a name="notion-heading-40ad9e129df78051a789c4f1dbe373a4"></a>

### 📃 b. WSL2 (우분투 설치)

- **WSL2** : Windows에서 Linux 환경을 실행할 수 있도록 지원하는 기능
- Windows를 유지하면서 Ubuntu의 개발 환경을 사용할 수 있음
- **활용** : Python 개발, ROS 2 학습, 리눅스 명령어 실습

<a name="notion-heading-40ad9e129df7801582b4f86afa445b38"></a>

### 📃 c. Directory Commands (폴더 이동 명령어)

| 명령어 | 기능 |
| --- | --- |
| `pwd` | 현재 경로 확인 |
| `ls` | 파일 및 폴더 목록 확인 |
| `cd 폴더명` | 해당 폴더로 이동 |
| `cd ..` | 상위 폴더로 이동 |
| `cd ~` | 홈 디렉터리로 이동 |
| `mkdir 폴더명` | 폴더 생성 |

<a name="notion-heading-40ad9e129df7809cb721cff7474785bc"></a>

### 📃 d. File Commands (파일 생성 및 관리)

| 명령어 | 기능 |
| --- | --- |
| `touch file.txt` | 빈 파일 생성 |
| `cat file.txt` | 파일 내용 출력 |
| `cp 원본 복사본` | 파일 복사 |
| `mv 기존 새이름` | 파일 이동 또는 이름 변경 |
| `rm file.txt` | 파일 삭제 |

<a name="notion-heading-40ad9e129df7803d9dc1e0a02de499ae"></a>

### 📃 e. File Edit Commands (파일 수정 명령어)

- `nano file.txt` : 터미널에서 파일 편집
- `vim file.txt` : Vim 편집기로 파일 수정
- `cat > file.txt` : 파일에 내용을 입력하고 저장
- `cat >> file.txt` : 기존 파일 내용 뒤에 추가

<a name="notion-heading-40ad9e129df7804c9142e5e086a67935"></a>

### 📃 f. Search Commands (검색 명령어)

| 명령어 | 기능 |
| --- | --- |
| `find . -name "*.py"` | 현재 경로에서 Python 파일 검색 |
| `grep "문자열" file.txt` | 파일에서 특정 문자열 검색 |
| `which python` | 실행 파일 경로 확인 |

<a name="notion-heading-40ad9e129df78003a884dd2283ac96eb"></a>

### 📃 g. Pipe and Redirection (파이프와 리디렉션)

- **Pipe (**`|`**)** : 앞 명령어의 결과를 뒤 명령어의 입력으로 전달
- **Redirection (**`>`**, **`>>`**)** : 명령어의 결과를 파일에 저장하거나 추가
- **Input Redirection (**`<`**)** : 파일 내용을 명령어의 입력으로 전달

```text
ls | grep ".py"          # Python 파일 검색
ls > list.txt            # 결과를 파일에 저장 (기존 내용 덮어쓰기)
ls >> list.txt           # 기존 파일에 결과 추가
sort < names.txt         # 파일 내용을 정렬
```
