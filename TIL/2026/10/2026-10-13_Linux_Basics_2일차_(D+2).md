## 📕 B. Linux 권한, 프로세스, 패키지 (2026.10.13 Tue)

### 📃 a. User (유저/사용자)

- **User**: Linux 시스템을 사용하는 개별 사용자 계정
- **root**: 시스템의 모든 권한을 가진 관리자 계정
- `whoami`: 현재 사용자 확인
- `sudo 명령어`: 관리자 권한으로 명령어 실행
- `passwd`: 사용자 비밀번호 변경

**💻 실습 예제**

```bash
# 현재 사용자 확인
whoami

# 패키지 목록 갱신 (관리자 권한 필요)
sudo apt update

# 현재 사용자의 비밀번호 변경
passwd
```

> 💡 `sudo`는 일반 사용자에게 관리자 권한이 필요한 명령어를 실행할 수 있도록 합니다.

### 📃 b. File Permission (파일 권한)

- 파일과 디렉터리에 대한 **읽기(r), 쓰기(w), 실행(x)** 권한을 설정
- 권한은 **소유자(User), 그룹(Group), 기타 사용자(Other)** 기준으로 구분

**📌 권한 기호와 숫자**

| 권한 | 의미 | 숫자 |
|---|---|---:|
| `r` | 읽기 (Read) | 4 |
| `w` | 쓰기 (Write) | 2 |
| `x` | 실행 (Execute) | 1 |

**📌 자주 사용하는 명령어**

| 명령어 | 기능 |
|---|---|
| `ls -l` | 파일 및 디렉터리 권한 확인 |
| `chmod` | 파일 및 디렉터리 권한 변경 |
| `chown` | 파일 및 디렉터리 소유자 변경 |

**💻 실습 예제**

```bash
# 파일 권한 확인
ls -l

# 소유자에게 모든 권한, 그룹과 기타 사용자에게 읽기 및 실행 권한 부여
chmod 755 script.sh

# 파일에 실행 권한 추가
chmod +x script.sh

# 변경된 권한 확인
ls -l script.sh
```

**💡 `755`의 의미**

| 대상 | 숫자 | 권한 |
|---|---:|---|
| 소유자 (User) | 7 (4+2+1) | 읽기 + 쓰기 + 실행 (rwx) |
| 그룹 (Group) | 5 (4+1) | 읽기 + 실행 (r-x) |
| 기타 사용자 (Other) | 5 (4+1) | 읽기 + 실행 (r-x) |

> ⚠️ `chmod 755 script.sh`를 실행하려면 해당 파일에 대한 권한이 있어야 합니다. 다른 사용자의 파일 등 권한이 없는 파일은 `sudo` 또는 적절한 소유권 설정이 필요할 수 있습니다.

### 📃 c. Group (그룹)

- **Group**: 여러 사용자에게 공통 권한을 부여하기 위한 사용자 집합
- 파일과 디렉터리의 권한을 그룹 단위로 관리할 수 있음

**📌 자주 사용하는 명령어**

| 명령어 | 기능 |
|---|---|
| `groups` | 현재 사용자가 속한 그룹 확인 |
| `id` | 사용자 ID 및 그룹 ID 확인 |
| `chgrp` | 파일 또는 디렉터리의 그룹 변경 |
| `usermod` | 사용자 계정의 그룹 설정 변경 |

**💻 실습 예제**

```bash
# 현재 사용자의 그룹 확인
groups

# 사용자 및 그룹 ID 확인
id

# file.txt의 그룹을 developers로 변경
sudo chgrp developers file.txt
```

> 💡 `developers` 그룹이 시스템에 존재해야 합니다. 그룹이 없다면 먼저 생성해야 하며, `chgrp` 명령어에는 파일의 소유권이나 관리자 권한 등 적절한 권한이 필요합니다.

### 📃 d. Processes (프로세스)

- **Process**: 현재 실행 중인 프로그램
- **PID (Process ID)**: 각 프로세스를 식별하는 고유 번호
- **Foreground**: 터미널에서 직접 실행되며 일반적으로 작업이 끝날 때까지 셸에서 다른 명령어를 입력하기 어려운 작업
- **Background**: 터미널에서 다른 작업을 수행하면서 백그라운드로 실행하는 작업

**📌 자주 사용하는 명령어**

| 명령어 | 기능 |
|---|---|
| `ps aux` | 실행 중인 프로세스 목록 확인 |
| `top` | 프로세스 및 시스템 자원 사용량 실시간 확인 |
| `kill PID` | 특정 PID의 프로세스에 종료 신호 전달 |
| `jobs` | 현재 셸에서 관리하는 작업 목록 확인 |
| `명령어 &` | 명령어를 백그라운드에서 실행 |

**💻 실습 예제**

```bash
# 실행 중인 프로세스 확인
ps aux

# 시스템 자원 및 프로세스 실시간 확인
top

# sleep 프로세스를 백그라운드로 실행
sleep 100 &

# 현재 셸의 작업 목록 확인
jobs
```

**📌 프로세스 종료 방법**

```bash
# 실제 PID 확인
ps aux

# 확인한 PID에 종료 신호 전달
kill PID
```

> ⚠️ `PID`는 설명을 위한 자리표시자입니다. 실제 명령어에는 `ps aux` 등으로 확인한 숫자 PID를 입력하세요. `kill`은 기본적으로 종료 요청 신호(SIGTERM)를 보내며, 프로세스가 즉시 종료되지 않을 수도 있습니다.

### 📃 e. Package (패키지)

- **Package**: 프로그램과 실행에 필요한 파일을 묶어 배포하는 단위
- **APT (Advanced Package Tool)**: Ubuntu에서 패키지를 설치하고 관리하는 도구

**📌 자주 사용하는 명령어**

| 명령어 | 기능 |
|---|---|
| `sudo apt update` | 패키지 목록 갱신 |
| `sudo apt upgrade` | 설치된 패키지 업데이트 |
| `sudo apt install 패키지명` | 패키지 설치 |
| `sudo apt remove 패키지명` | 패키지 제거 |
| `apt search 검색어` | 패키지 검색 |

**💻 실습 예제**

```bash
# 패키지 목록 갱신
sudo apt update

# Git 설치
sudo apt install git

# Git 버전 확인
git --version

# git 관련 패키지 검색
apt search git
```

> 💡 `apt update`는 패키지 목록을 갱신하는 명령어이고, `apt upgrade`는 갱신된 목록을 바탕으로 설치된 패키지를 업데이트하는 명령어입니다.
