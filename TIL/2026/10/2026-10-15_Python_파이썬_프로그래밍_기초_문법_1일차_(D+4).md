### 📃 c. Input and Output (입력과 출력, 변수와 데이터 타입)

- **변수(Variable)** : 데이터를 저장하는 이름
- **입력(Input)** : `input()`으로 사용자 입력 받기
- **출력(Output)** : `print()`로 결과 출력
- **데이터 타입(Data Type)** : 데이터의 종류

| 타입 | 의미 | 예시 |
| --- | --- | --- |
| `int` | 정수 | `10` |
| `float` | 실수 | `3.14` |
| `str` | 문자열 | `"Robot"` |
| `bool` | 참·거짓 | `True`, `False` |
| `list` | 여러 값을 저장하는 목록 | `[1, 2, 3]` |

```text
name = input("이름을 입력하세요: ")
age = int(input("나이를 입력하세요: "))

print(name, age)
print(type(age))
```

※ `input()`은 기본적으로 문자열(`str`)을 반환하므로 숫자로 사용하려면 `int()` 또는 `float()`으로 변환해야 합니다.

### 📃 d. Operators (산술, 비교, 논리, 멤버십 연산자)

- **산술 연산자** : 수학적 계산
- **비교 연산자** : 두 값의 크기나 동일 여부 비교
- **논리 연산자** : 여러 조건을 조합
- **멤버십 연산자** : 특정 값이 데이터에 포함되어 있는지 확인

| 종류 | 연산자 | 예시 |
| --- | --- | --- |
| 산술 | `+`, `-`, `*`, `/`, `//`, `%`, `**` | `10 % 3 → 1` |
| 비교 | `==`, `!=`, `>`, `<`, `>=`, `<=` | `10 > 5 → True` |
| 논리 | `and`, `or`, `not` | `True and False → False` |
| 멤버십 | `in`, `not in` | `"a" in "cat" → True` |

<a name="notion-heading-40ad9e129df780f5a1f1d52db5f72478"></a>

### 📃 e. Conditionals (조건문)

- **조건문** : 조건의 참·거짓에 따라 실행할 코드를 결정
- `if` : 조건이 참일 때 실행
- `elif` : 다른 조건 추가
- `else` : 앞선 조건이 모두 거짓일 때 실행
- Python은 **들여쓰기(Indentation)** 로 코드 블록을 구분

```text
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

<a name="notion-heading-40ad9e129df78001bdf5d983c6a56849"></a>

### 📃 f. Loops (반복문)

- **반복문** : 동일한 작업을 여러 번 실행
- `for` : 시퀀스의 항목을 순서대로 반복
- `while` : 조건이 참인 동안 반복
- `range()` : 숫자 범위를 생성

```text
for i in range(3):
    print(i)  # 0, 1, 2
```

```text
count = 0

while count < 3:
    print(count)
    count += 1
```

- `break` : 반복문 종료
- `continue` : 현재 반복을 건너뛰고 다음 반복으로 이동
