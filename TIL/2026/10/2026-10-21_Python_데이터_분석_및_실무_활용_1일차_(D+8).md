### 📃 b. NumPy (고속 수치 계산의 기반)

- <strong>NumPy</strong> : 배열(Array)을 기반으로 대량의 숫자 데이터를 효율적으로 계산하는 Python 라이브러리
- <strong>ndarray</strong> : NumPy의 핵심 자료구조인 다차원 배열
- Python 리스트보다 수치 연산에 효율적이며, 여러 요소에 연산을 한 번에 적용할 수 있음 (<strong>Vectorization</strong>)

```text
import numpy as np

arr = np.array([1, 2, 3, 4, 5])

print(arr * 2)      # [ 2  4  6  8 10]
print(arr.mean())   # 3.0
print(arr.sum())    # 15
```

<a name="notion-heading-40ad9e129df780f9b6b7f04867237d60"></a>

### 📃 NumPy 주요 기능

| 문법 | 기능 |
| --- | --- |
| `np.array()` | 배열 생성 |
| `np.zeros((2, 3))` | 0으로 채운 배열 생성 |
| `np.ones((2, 3))` | 1로 채운 배열 생성 |
| `np.arange(0, 10, 2)` | 일정 간격의 배열 생성 |
| `arr.shape` | 배열의 형태 확인 |
| `arr.ndim` | 배열의 차원 확인 |
| `arr.reshape()` | 배열 형태 변경 |
| `arr.mean()` | 평균 계산 |
| `arr.sum()` | 합계 계산 |
| `arr.max()` / `arr.min()` | 최댓값 / 최솟값 계산 |

<a name="notion-heading-40ad9e129df780ca9871ea121f61f1f8"></a>

### 📃 배열 연산 (Vectorization)

- 반복문 없이 배열의 여러 요소에 연산을 한 번에 적용
- 대량의 수치 데이터 처리에 유용

```text
import numpy as np

a = np.array([10, 20, 30])
b = np.array([1, 2, 3])

print(a + b)  # [11 22 33]
print(a * b)  # [10 40 90]
```

<a name="notion-heading-40ad9e129df780f7a3d5c83c617aa022"></a>

### 📃 다차원 배열 (Dimensions)

- <strong>1차원 배열</strong> : 숫자가 일렬로 나열된 형태
- <strong>2차원 배열</strong> : 행(Row)과 열(Column)로 구성된 형태
- `shape` : 각 차원의 크기를 확인하는 속성

```text
arr = np.array([[1, 2, 3],
                [4, 5, 6]])

print(arr.shape)  # (2, 3)
print(arr.ndim)   # 2
```
