## 📚 1주차 Linux (2026.10.12 Mon ~ 2026.10.14 Wed) | Total : 3 days

### 📕 A. Linux 기초 (2026.10.12 Mon)

- 리눅스(Linux)란? 오픈소스 기반의 유닉스(Unix) 계열 운영체제로, 서버, 임베디드 시스템, 개발 환경에서 널리 사용됩니다. 안정성과 보안성이 뛰어납니다.
- 우분투(Ubuntu)란? 리눅스 배포판 중 하나로, 사용자 친화적이고 커뮤니티 지원이 활발하여 개발자들이 입문할 때 가장 많이 사용하는 OS입니다.
- WSL2 (Windows Subsystem for Linux 2): 윈도우 환경에서 가상머신(VM)의 무거움 없이 네이티브 리눅스(우분투)를 실행할 수 있게 해주는 마이크로소프트의 기능입니다.
- 설치 방법 (요약):
디렉토리(폴더)를 확인하고 이동하는 기본 커맨드입니다.

- pwd : 현재 내가 위치한 디렉토리의 절대 경로 출력 (Print Working Directory)
- ls : 현재 디렉토리의 파일 및 폴더 목록 조회
- cd [경로] : 디렉토리 이동 (Change Directory)
파일과 디렉토리를 생성, 복사, 이동, 삭제하는 커맨드입니다.

- touch [파일명] : 크기가 0인 빈 파일 생성 또는 파일의 수정 시간 업데이트
- mkdir [디렉토리명] :새로운 디렉토리 생성 (p 옵션으로 하위 디렉토리 동시 생성 가능)
- cp [원본] [복사본] : 파일 또는 디렉토리 복사
- mv [이름1] [이름2] : 파일/디렉토리 이름 변경 또는 다른 위치로 이동
- rm [파일명] : 파일 삭제 (rf 옵션으로 디렉토리 강제 삭제 주의)
터미널 환경에서 파일을 직접 읽고 수정하는 툴/커맨드입니다.

- cat [파일명] : 파일의 전체 내용을 화면에 출력
- nano [파일명] : 초보자가 사용하기 가장 쉬운 터미널 내 텍스트 편집기 (하단 안내에 따라 저장/종료 가능)
- vi 또는 vim : 강력하지만 숙련이 필요한 리눅스 표준 텍스트 편집기 (입력 모드 i, 저장 및 종료 :wq)
파일이나 파일 안의 문자열을 찾아내는 커맨드입니다.

- find [경로] -name [파일명] : 특정 조건의 파일/디렉토리 검색
- grep "[검색어] [파일명]" : 파일 내에서 특정 문자열이 포함된 라인 검색
명령어의 흐름을 제어하고 입출력을 연결하는 핵심 기능입니다.

- 리디렉션 (>, >>): 출력 방향을 화면이 아닌 파일로 보냅니다.
- 파이프 (|): 앞선 명령어의 출력을 다음 명령어의 입력으로 전달합니다.
