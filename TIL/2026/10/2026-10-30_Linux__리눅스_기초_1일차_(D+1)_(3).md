# 📚 1주차 Linux (2026.10.12 Mon ~ 2026.10.14 Wed) | Total : 3 days

## 📕 A. Linux 기초 (2026.10.12 Mon)

### 📃 a. Linux & Ubuntu (리눅스 소개)
- 리눅스(Linux) & 우분투(Ubuntu) 개요
  - **리눅스(Linux):** 오픈소스 기반의 유닉스(Unix) 계열 운영체제 (안정성 및 보안성 우수)
  - **우분투(Ubuntu):** 사용자 친화적인 리눅스 대표 배포판 (풍부한 커뮤니티 지원)

### 📃 b. WSL2 (우분투 설치)
- WSL2 (Windows Subsystem for Linux 2)
  - **개념:** 가상머신(VM) 없이 윈도우 환경에서 네이티브 리눅스를 동작시키는 서브시스템
  - **설치 절차**
    - 1단계: PowerShell(관리자 권한) 실행 후 명령어 입력 (`wsl --install`)
    - 2단계: 재부팅 실행 후 Microsoft Store에서 Ubuntu 설치 및 계정 설정

### 📃 c. Directory Commands (폴더 이동 커멘드)
- 디렉토리 및 경로 커맨드
  - `pwd` : 현재 작업 중인 디렉토리의 절대 경로 출력
  - `ls` : 현재 디렉토리 파일 및 폴더 목록 확인
    - `ls -l` : 권한, 소유자, 용량 등 상세 정보 포함 출력
    - `ls -a` : 숨김 파일(.)을 포함한 전체 목록 출력
  - `cd [경로]` : 지정한 디렉토리 위치로 이동
    - `cd ..` : 상위 디렉토리로 이동
    - `cd ~` : 홈 디렉토리로 이동

### 📃 d. File Commands (파일 생성, 작성 커맨드)
- 파일 및 디렉토리 관리 커맨드
  - **생성 및 관리**
    - `touch [파일명]` : 빈 파일 생성 및 파일 수정 시간 업데이트
    - `mkdir [디렉토리명]` : 신규 디렉토리 생성 (`-p` 옵션 적용 시 하위 경로 일괄 생성)
  - **복사 및 이동**
    - `cp [원본] [복사본]` : 파일 또는 디렉토리 복사 (`-r` 옵션 적용)
    - `mv [이름1] [이름2]` : 파일/디렉토리 이름 변경 또는 지정 경로로 이동
  - **삭제**
    - `rm [파일명]` : 지정 파일 삭제 (`-rf` 옵션 적용 시 디렉토리 강제 삭제)

### 📃 e. File Edit Commands (파일 수정 커맨드)
- 파일 수정 및 편집 커맨드
  - **내용 확인:** `cat [파일명]` (파일의 전반적인 내용 출력)
  - **텍스트 편집기 (Nano):** `nano [파일명]` (직관적인 인터페이스의 터미널 텍스트 에디터)
  - **텍스트 편집기 (Vim)**
    - `vi` 또는 `vim` : 표준 리눅스 에디터
    - `i` : 입력 모드(Insert) 진입
    - `:wq` : 저장 후 종료

### 📃 f. Search Commands (검색 커맨드)
- 검색 커맨드
  - **파일 검색:** `find [경로] -name [파일명]` (지정 디렉토리 내 조건에 부합하는 파일 탐색)
  - **문자열 검색:** `grep "[검색어]" [파일명]` (파일 내부에서 특정 문자열 패턴이 포함된 행 추출)

### 📃 g. Pipe and Redirection (파이프와 리디렉션)
- 파이프와 리디렉션
  - **리디렉션 (Redirection)**
    - `command > file` : 출력을 파일로 전달 (기존 내용 덮어쓰기)
    - `command >> file` : 출력을 파일로 전달 (기존 내용 하단 이어쓰기)
  - **파이프 (Pipe)**
    - `command1 | command2` : 앞 명령어의 출력 결과를 뒤 명령어의 입력으로 전달
    - 예시: `ls -l | grep ".txt"` (전체 파일 목록 중 `.txt` 포함 항목 필터링)
