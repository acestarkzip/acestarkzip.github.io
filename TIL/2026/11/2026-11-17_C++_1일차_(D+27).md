## 1. C++ 소개 및 개발 환경 구축

- <strong>C++ 특징:</strong> 기계어로 직접 컴파일되어 실행 속도가 매우 빠르며, 하드웨어(메모리 등)에 직접 접근할 수 있는 고성능 언어입니다. 임베디드, 게임 엔진, OS/드라이버, 고성능 컴퓨팅, 금융, 딥러닝 프레임워크(PyTorch, TensorFlow 코어), 로보틱스(ROS) 등에 활용됩니다.
- C vs C++ 주요 차이점:
    - <strong>객체지향 패러다임:</strong> C에는 클래스(class)와 객체지향(OOP) 개념이 없지만 C++은 이를 지원합니다.
    - <strong>자원 관리:</strong> C는 `malloc`과 `free`로 직접 메모리를 확보하고 해제해야 합니다.
    - <strong>타입 안정성:</strong> C++은 템플릿과 `auto` 등을 통해 컴파일 시점에 더 엄격한 타입 검사를 수행합니다.
- <strong>IDE &amp; 컴파일러 설치:</strong>
    - <strong>VS Code:</strong> 코드 에디터, 컴파일러, 디버거 기능을 통합 지원하는 무료 IDE로, 설치 시 반드시 `PATH에 추가` 옵션을 선택해야 합니다.
    - <strong>GCC / G++:</strong> `gcc`는 C/C++를 구분해 컴파일하며 C++ 표준 라이브러리를 자동 연결하지 않지만, `g++`는 `.c` 파일도 C++로 취급하고 링크 시 C++ 표준 라이브러리를 자동 연결합니다.
    - <strong>환경 변수 설정:</strong> MSYS2 UCRT64에서 `pacman -S mingw-w64-ucrt-x86_64-gcc`로 설치한 후, Windows 시스템 환경 변수 `Path`에 `C:\msys64\ucrt64\bin`을 추가합니다.
- <strong>컴파일 및 실행 과정:</strong>
    - 컴파일 명령어 `g++ test.cpp` (또는 실행 파일명 지정 시 `g++ test.cpp -o test.exe`)를 입력하면 <strong>전처리(Preprocessing) → 컴파일(Compile) → 어셈블리(Assembly) → 링크(Link)</strong> 4단계를 거쳐 실행 파일이 생성됩니다.

## 2. 출력 (Output)

<a name="notion-heading-41cd9e129df780acbd6bfb0cb7094521"></a>

### C++

```cpp
#include <iostream>
using namespace std;

int main(){
    cout << "Hello world!\n";
    return 0;
}
```

- `#include <iostream>`: 표준 입출력 헤더 파일을 불러오는 전처리 지시자입니다.
- `using namespace std;`: 표준 라이브러리의 `std` 네임스페이스를 생략하게 해주며, 큰 프로젝트에서는 이름 충돌 방지를 위해 `std::cout` 형태로 쓰는 것이 권장됩니다.
- `int main()`: 프로그램의 진입점이며, 관례상 `0` 반환은 정상 종료를 의미합니다(생략 시 컴파일러가 자동 추가).
- `cout <<`: 데이터를 표준 출력 스트림으로 보내며, 줄바꿈은 자동 처리되지 않으므로 개행 문자(`'\n'`)를 직접 넣어야 합니다.

<a name="notion-heading-41cd9e129df780b0b04ddf45082d2dc9"></a>

## 3. 변수와 데이터 타입 (Variables)

- <strong>선언과 초기화:</strong> 변수 선언(`int age;`) 시 메모리 공간이 확보되고 기존 잔여 데이터인 <strong>쓰레기값</strong>이 들어 있으며, 대입 연산자(`=`)로 값을 넣는 과정을 초기화(`int height = 135;`)라고 합니다.
- <strong>변수명 규칙:</strong> 영문 대소문자, 숫자, 언더스코어(`_`)만 사용 가능하며 숫자로 시작하거나 예약어(`if`, `for` 등)를 쓸 수 없고, 관례상 `camelCase`를 사용합니다.
- 주요 데이터 타입 요약:

| <strong>타입</strong> | <strong>크기</strong> | <strong>표현 범위 / 특징</strong> |
| --- | --- | --- |
| `bool` | 1바이트    | `true` / `false` (기본적으로 1과 0으로 표현)    |
| `char` | 1바이트    | `-128 ~ 127` (정수 대입 시 ASCII 문자로 변환 출력)    |
| `short` | 2바이트    | `-32,768 ~ 32,767`    |
| `int` | 4바이트    | 약 `-21억 ~ 21억` (`unsigned int`는 `0 ~ 약 42억`)    |
| `long long` | 8바이트    | 약 $-9.2 \times 10^{18} \sim 9.2 \times 10^{18}$    |
| `float` / `double` | 4바이트 / 8바이트    | 실수형 (유효자리 약 6~7자리 / 약 15~16자리)    |

<a name="notion-heading-41cd9e129df780a2b784d1aa2aef92a1"></a>

## 4. 배열 (Array)

- <strong>개념 및 인덱싱:</strong> 같은 자료형의 변수들을 연속된 메모리에 나열한 자료구조로, `0`번부터 `크기 - 1`번까지의 인덱스로 빠르게 접근합니다.
- <strong>초기화:</strong> `int arr[10] = {0,};`처럼 일부만 초기화하면 나머지 요소는 자동으로 `0`으로 채워집니다.
- <strong>주의사항:</strong> 배열 범위를 벗어난 양수 인덱스에 접근해도 컴파일 에러가 발생하지 않고 인접 메모리의 쓰레기값을 읽어오므로 주의해야 합니다.

<a name="notion-heading-41cd9e129df780f889dbc4d09f0d4421"></a>

## 5. 입력 (Input)

- <strong>기본 입력:</strong> `cin >> a;`를 통해 공백이나 줄바꿈(`\n`) 단위로 구분하여 데이터를 입력받습니다.
- <strong>예외 처리(C++11 기준):</strong> 자료형과 맞지 않는 값을 입력하면 `0`이 대입되며, `int` 범위를 초과하는 큰 정수를 입력하면 해당 자료형의 최댓값(`INT_MAX`, `2147483647`)이 대입됩니다.
- <strong>Windows 콘솔 한글 깨짐 해결:</strong> `<windows.h>` 헤더를 추가하고 `SetConsoleOutputCP(CP_UTF8);` 및 `SetConsoleCP(CP_UTF8);`를 호출합니다.

<a name="notion-heading-41cd9e129df7807f8b11e156fd86787f"></a>

## 6. 연산자 (Operators)

- <strong>산술 연산자:</strong> `+`, , , `/` (정수 나눗셈은 몫 반환), `%` (나머지 반환)
- <strong>비교 연산자:</strong> `==`, `!=`, `>`, `<`, `>=`, `<=` (결과를 불리언으로 반환)
- <strong>논리 연산자:</strong> `&&` (AND, 모두 참일 때 참), `||` (OR, 하나라도 참이면 참), `!` (NOT, 결과 반전)
- <strong>혼합 대입 &amp; 증감 연산자:</strong> `+=`, `=`, `=`, `/=`, `%=`로 연산과 대입을 동시에 수행하며, 전위(`++a`)는 증감 후 사용, 후위(`a++`)는 사용 후 증감합니다.

<a name="notion-heading-41cd9e129df78015a902dbb960297d2f"></a>

## 7. 조건문 (Conditionals)

- <strong>구조:</strong> `if`, `else if`, `else`를 사용해 조건의 참/거짓에 따라 실행 흐름을 분기하며, 실행 코드가 1줄일 경우 중괄호(`{}`)를 생략할 수 있습니다.
- 자주 하는 실수 3가지:
    1. 비교(`==`) 대신 대입(`=`) 연산자 사용
    1. 범위 비교 시 `1 <= a <= 10`처럼 작성 (반드시 `1 <= a && a <= 10`으로 작성해야 함)
    1. 다중 값 비교 시 나열 작성 (반드시 `a == 1 || a == 2`처럼 `||`로 연결해야 함)

<a name="notion-heading-41cd9e129df780e19f5dd26edd5f2d6a"></a>

## 8. 반복문 (Loops)

- `for`<strong> 문:</strong> `for(초기식; 조건식; 증감식)` 형태로 주로 반복 횟수가 정해져 있을 때 사용합니다.
- `while`<strong> 문:</strong> `while(조건)` 형태로 특정 조건을 만족할 때까지 반복할 때 주로 사용합니다.
- <strong>제어 키워드:</strong>
    - `break`: 반복문을 즉시 종료하고 탈출합니다.
    - `continue`: 아래 코드를 건너뛰고 다음 반복 회차로 넘어갑니다 (`while` 문에서 증감식보다 앞에 위치하면 무한 루프에 빠질 수 있으므로 주의해야 합니다).
