## 1. 문자와 문자열 (`char`, `string`)

- <strong>문자(</strong>`char`<strong>) 특징:</strong> 1바이트 크기의 문자 1개를 저장하며 홀따옴표(`' '`)로 감싸서 표현합니다. ASCII 코드표에 따라 고유 숫자와 대응되며, 정수나 다른 `char`와 `+` 연산 시 `int`로 자동 변환됩니다. `(char)` 또는 `(int)`로 형변환(type casting)하여 문자와 정수를 오갈 수 있습니다.
- <strong>문자열(</strong>`string`<strong>) 특징:</strong> 쌍따옴표(`" "`)로 감싸 표현하며 `<string>` 헤더를 포함하는 것이 권장됩니다. 문자 배열처럼 인덱싱으로 각 글자에 접근·수정할 수 있고, 끝에는 항상 널 문자(`'\0'`)가 포함되며 `+` 연산자로 문자열 결합(concatenation)이 가능합니다.
- <strong>주요 </strong>`string`<strong> 메서드:</strong>
  - `size()`: 널 문자를 제외한 문자열 길이를 부호 없는 정수(`size_t`)로 반환하므로 `int`와 연산할 때는 `(int)a.size()`로 형변환하는 것이 안전합니다.
  - `substr(index, count)`: `index` 위치부터 `count`개(생략 시 끝까지)의 부분 문자열을 잘라 반환합니다.
  - `find("str", index)`: `index`부터 `"str"`이 처음 등장하는 위치를 반환하며, 찾지 못하면 `string::npos`를 반환합니다.

<div class="notion-spacer" aria-hidden="true" style="height:1.5rem;min-height:1.5rem;"></div>

<a name="notion-heading-41cd9e129df78086a1d2d4103d55dec3"></a>

### C++

```cpp
// find와 substr을 활용한 문자열 파싱(parsing) 예시
string s = "abc,def,ghi";
int idx = 0, pos = -1;
while ((pos = s.find(",", idx)) != string::npos) {
    cout << s.substr(idx, pos - idx) << '\n';
    idx = pos + 1;
}
cout << s.substr(idx) << '\n';
```

## 2. 함수 (`Function`)

- <strong>구조와 동작:</strong> `반환자료형 함수명(매개변수)` 형태로 정의하며, `return` 문을 만나면 반환값을 가지고 호출되었던 위치로 복귀합니다. 반환값이 없는 경우 `void`를 사용합니다.
- <strong>지역 변수 vs 전역 변수:</strong>
  - <strong>지역 변수:</strong> 함수 내부나 매개변수로 선언되며 해당 함수 안에서만 유효하고 종료 시 사라집니다.
  - <strong>전역 변수:</strong> 함수 외부에 선언되어 모든 함수에서 접근 가능하며 변경 사항이 유지됩니다.
- <strong>함수와 배열:</strong> 배열을 함수에 넘길 때는 배열 이름(첫 번째 요소의 메모리 주소)이 전달되므로 함수 내부에서 요소를 수정하면 원본 배열에도 반영됩니다. C++ 특성상 배열 자체를 직접 반환하는 함수는 만들 수 없습니다.

## 3. 포인터 (`Pointer`)

- <strong>개념 및 활용 목적:</strong> 값이 아닌 메모리 주소 자체를 저장하고 다루는 변수로, 대용량 데이터를 복사 없이 전달하거나 원본 값을 직접 수정하고 연결리스트 같은 자료구조를 구현할 때 사용합니다.
- <strong>핵심 연산자:</strong>
  - `&` (주소 연산자): 변수가 저장된 메모리 주소를 가져옵니다.
  -  (역참조 연산자): 포인터가 가리키는 메모리 주소에 저장된 실제 값에 접근하거나 값을 변경합니다. 포인터의 자료형은 가리킬 변수의 자료형과 반드시 일치해야 합니다.
- <strong>배열과 포인터:</strong> 배열의 이름 자체가 첫 번째 요소의 주소(포인터)이며, `(p + i)`처럼 포인터 연산을 통해 연속된 메모리에 접근할 수 있습니다.
- <strong>Call by Value vs Call by Reference:</strong>
  - <strong>Call by Value:</strong> 값을 복사해서 전달하므로 원본 변수는 변하지 않습니다.
  - <strong>Call by Reference:</strong> 메모리 주소(포인터)를 전달해 원본 값을 직접 수정하며, 함수가 여러 결과값을 변경·반환하는 효과를 낼 수 있습니다.

<a name="notion-heading-41cd9e129df780f98189c8881e62d4bf"></a>

### C++

```cpp
// 포인터를 활용한 swap 함수
void swap(int *a, int *b){
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

## 4. 구조체와 클래스 (`struct`, `class`)

- <strong>사용자 정의 자료형 (</strong>`struct`<strong> vs </strong>`class`<strong>):</strong> 여러 속성(변수)과 메서드(함수)를 하나로 묶어 관리하기 위해 사용하며, 정의 끝에는 반드시 세미콜론(`;`)을 붙입니다.

| <strong>구분</strong> | <strong>struct</strong> | <strong>class</strong> |
| --- | --- | --- |
| <strong>멤버 기본 접근 권한</strong> | `public` (모두 공개)    | `private` (비공개)    |
| <strong>기본 상속 방식</strong> | `public` 상속    | `private` 상속    |

- <strong>캡슐화(Encapsulation)와 접근 지정자:</strong>
  - `public`: 클래스 외부 어디서든 접근 가능합니다.
  - `protected`: 해당 클래스와 상속받은 자식 클래스 내부에서만 접근 가능합니다.
  - `private`: 해당 클래스 내부에서만 접근 가능하며, 외부에서 읽고 쓸 때는 `public`으로 선언된 `getter`와 `setter` 함수를 통해 제어합니다.
- <strong>생성자(Constructor)와 상속(Inheritance):</strong>
  - <strong>생성자:</strong> 인스턴스 생성 시 멤버 변수를 초기화하는 함수입니다.
  - <strong>상속:</strong> `class 자식 : public 부모` 형태로 기존 클래스의 속성과 메서드를 물려받아 확장합니다.
- <strong>다형성(Polymorphism)과 추상 클래스(Abstract Class):</strong>
  - <strong>오버로딩(Overloading):</strong> 같은 이름의 함수를 매개변수의 개수·타입·순서만 다르게 여러 개 정의하는 기법입니다. 자식 클래스에서 부모의 오버로딩된 함수를 모두 쓰려면 `using 부모클래스::함수명;`을 선언해야 합니다.
  - <strong>오버라이딩(Overriding)과 </strong>`virtual`<strong>:</strong> 부모 클래스의 함수를 자식 클래스에서 재정의하는 것으로, 포인터로 다룰 때도 실제 객체의 함수가 실행되려면 부모 함수에 `virtual`을, 자식 함수에 `override`를 명시해야 합니다.
  - <strong>추상 클래스:</strong> `virtual void grade() const = 0;`처럼 순수 가상 함수를 하나 이상 포함한 클래스로, 직접 인스턴스를 생성할 수 없으며 자식 클래스에서 반드시 해당 함수를 오버라이딩해야 합니다.

## 5. 정렬 (`sort`)

- <strong>기본 배열 정렬:</strong> `<algorithm>` 헤더를 포함하고 `sort(시작주소, 끝주소)` 형태로 호출합니다.
  - 오름차순(기본): `sort(arr, arr + 5);`
  - 내림차순: `sort(arr, arr + 5, greater<int>());`
- <strong>구조체 / 클래스 사용자 정의 정렬:</strong> 기본 비교 기준(`<`)이 없으므로 아래 두 가지 방법 중 하나를 구현해야 합니다.
  1. <strong>비교 함수(</strong>`cmp`<strong>) 전달:</strong> `bool cmp(Point a, Point b)` 함수를 정의하여 `sort(points, points + 4, cmp);`의 세 번째 인자로 넘깁니다.
  1. `<`<strong> 연산자 오버로딩:</strong> 구조체/클래스 내부에 `bool operator < (const Point o) const`를 정의하여 기본 `sort(points, points + 4);`로 정렬되도록 만듭니다.

<div class="notion-spacer" aria-hidden="true" style="height:1.5rem;min-height:1.5rem;"></div>

<a name="notion-heading-41cd9e129df7803789dae1899ed24c75"></a>

### C++

```cpp
struct Point {
    int y, x;
    bool operator < (const Point o) const {
        if (y == o.y) return x < o.x; // y가 같으면 x 오름차순
        return y < o.y;               // y 오름차순
    }
};
```
