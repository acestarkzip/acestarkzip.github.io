## 📕 1. NVIDIA DLI Robotics 교육 소개

<a name="notion-heading-423d9e129df780d09ad2e5394fd5b3df"></a>

### 📄 1-1. NVIDIA DLI Robotics 교육 로드맵

NVIDIA DLI Robotics 교육은 로봇 시뮬레이션부터 AI 학습, ROS 2 가속, 디지털 트윈 및 OpenUSD 인증까지 단계적으로 학습하는 과정입니다.

- DLI 1: Robotics Foundations
- DLI 2: Getting Started with Isaac Sim
- DLI 3: Getting Started with Isaac Lab
- DLI 4: Getting Started with Isaac ROS
- DLI 5~6: Robotics 및 Digital Twins
- DLI 7~8: Simulation, Synthetic Data 및 OpenUSD Certification

<a name="notion-heading-423d9e129df7807bbb62d9d57210c7c9"></a>

### 📄 1-2. 개발환경 구성

로보틱스 시뮬레이션을 위한 기본 개발환경을 구축합니다.

- OS: Ubuntu 24.04 LTS
- Simulation: NVIDIA Isaac Sim 5.1
- Robotics Framework: ROS 2 Jazzy
- Navigation: Nav2
- Development Tool: VS Code, Terminator
- Python: venv 기반 가상환경

모든 교육 자료와 실습 파일은 `~/nvidia_dli` 작업 폴더를 중심으로 관리합니다.

## 📕 2. 자율로봇과 Embodied AI의 이해

<a name="notion-heading-423d9e129df7803a863ef959a29cd1d0"></a>

### 📄 2-1. 자율로봇(Autonomous Robot)이란?

자율로봇은 사람이 모든 동작을 직접 조종하지 않아도 주변 환경을 감지하고, 상황을 판단하며, 스스로 움직이는 로봇입니다.

기본적인 동작 과정은 다음과 같습니다.

- Sense: 주변 환경 감지
- Plan: 상황 판단 및 행동 계획
- Act: 실제 동작 수행

대표적인 자율로봇 종류는 다음과 같습니다.

- 자율이동로봇(AMR)
- 로봇팔(Manipulator)
- 4족 보행 로봇
- 휴머노이드(Humanoid)
- 자율주행차
- 드론 및 수중 로봇

<a name="notion-heading-423d9e129df780269fcce7e69ab6bd9e"></a>

### 📄 2-2. Embodied AI와 HRI

Embodied AI는 센서와 모터 등 물리적인 신체를 통해 실제 환경과 상호작용하고 학습하며 행동하는 AI를 의미합니다.

HRI(Human-Robot Interaction)는 사람과 로봇이 서로 소통하고 협력하는 기술입니다.

주요 고려사항은 다음과 같습니다.

- 안전성: 사람을 감지하고 상황에 따라 속도와 힘을 제한합니다.
- 의도 전달: 로봇의 움직임과 상태를 사람에게 전달합니다.
- 상호작용: 음성 및 몸짓 등을 통해 사람의 지시를 이해합니다.

<a name="notion-heading-423d9e129df780d78a47e54b6f20ddc6"></a>

### 📄 2-3. 로봇 시스템 통합

로봇 시스템은 하드웨어와 소프트웨어, 주변 환경이 하나의 시스템으로 동작하도록 통합해야 합니다.

주요 구성요소는 센서, 제어기, 액추에이터 및 통신 시스템입니다.

특히 센서 간 시간 동기화, 좌표계(TF), 통신 지연 등의 문제를 함께 고려해야 합니다.

## 📕 3. 자율화 기술의 핵심 구성요소

<a name="notion-heading-423d9e129df780e185cdfa4e3b41beb5"></a>

### 📄 3-1. 센싱(Sensing)

센싱은 로봇이 주변 환경과 자신의 상태를 파악하기 위해 센서 데이터를 수집하는 과정입니다.

대표적인 센서는 다음과 같습니다.

- RGB Camera: 색상 및 영상 정보 수집
- Stereo Camera: 거리 및 깊이 정보 측정
- LiDAR: 주변 환경의 거리와 3D 공간 정보 측정
- IMU: 가속도와 각속도 측정
- Wheel Encoder: 바퀴 회전량 측정
- Force / Touch Sensor: 접촉 및 힘 감지

하나의 센서만으로 모든 환경을 파악하기는 어렵기 때문에 여러 센서의 장점을 결합하는 센서 융합(Sensor Fusion)이 중요합니다.

<a name="notion-heading-423d9e129df780e4812bedf02bdfaee9"></a>

### 📄 3-2. 인지(Perception)

인지 기술은 수집한 센서 데이터를 분석하여 주변 환경의 의미를 이해하는 과정입니다.

- Detection: 물체의 종류와 위치 검출
- Segmentation: 이미지의 픽셀 단위로 객체 구분
- Depth Estimation: 물체까지의 거리 추정
- Pose Estimation: 물체의 위치와 방향 추정

<a name="notion-heading-423d9e129df780ecbeb0cd5c90516b1a"></a>

### 📄 3-3. 위치추정과 지도(Localization and Mapping)

로봇이 현재 자신의 위치를 파악하고 주변 환경의 지도를 활용하는 기술입니다.

- Odometry: 바퀴 회전량 등을 기반으로 이동 거리와 위치 추정
- Localization: 지도 안에서 현재 로봇의 위치 추정
- SLAM: 위치추정과 지도 생성을 동시에 수행

바퀴 회전량만으로 위치를 계산하면 미끄러짐이나 바퀴 마모 등으로 오차가 누적됩니다.

따라서 카메라와 LiDAR 등의 센서 정보를 활용하여 위치를 지속적으로 보정해야 합니다.

<a name="notion-heading-423d9e129df78032b1a2e371a6ed0a3c"></a>

### 📄 3-4. 경로계획과 내비게이션(Navigation)

로봇이 출발지에서 목적지까지 안전하게 이동하기 위한 경로를 계산하는 기술입니다.

- Global Planning: 전체 지도에서 목적지까지의 경로 계획
- Local Planning: 주변 장애물과 환경 변화에 대응하며 이동 경로 조정
- Navigation: 위치추정, 경로계획 및 주행을 통합한 이동 과정

대표적인 경로탐색 알고리즘에는 A*와 Dijkstra가 있습니다.

<a name="notion-heading-423d9e129df7802ca1f0f99ca6078d32"></a>

### 📄 3-5. 제어(Control Systems)

제어는 계획된 움직임을 실제 모터와 액추에이터에 전달하여 로봇을 움직이는 기술입니다.

대표적인 제어 알고리즘인 PID는 다음 세 가지 요소로 구성됩니다.

- P(Proportional): 현재 오차에 비례하여 제어합니다.
- I(Integral): 누적된 오차를 보정합니다.
- D(Derivative): 오차 변화율을 활용하여 오버슈트를 줄입니다.

제어기의 각 이득값(Kp, Ki, Kd)에 따라 로봇의 응답 속도와 안정성이 달라집니다.

## 📕 4. 로보틱스 기초 알고리즘 실습

<a name="notion-heading-423d9e129df780c69f09e7a71ae48bfa"></a>

### 📄 4-1. 차동구동 기구학(Differential Drive Kinematics)

차동구동은 좌우 두 바퀴의 회전 속도 차이를 이용하여 로봇의 이동과 회전을 제어하는 방식입니다.

- 좌우 바퀴가 같은 방향과 속도로 회전하면 직진합니다.
- 좌우 바퀴의 속도가 다르면 회전합니다.
- 좌우 바퀴가 반대 방향으로 회전하면 제자리 회전합니다.

바퀴 반지름(r)과 바퀴 간격(L)을 기반으로 로봇의 선속도와 각속도를 계산합니다.

<a name="notion-heading-423d9e129df78074a180f1cd9bdd1a25"></a>

### 📄 4-2. 오도메트리(Odometry)

오도메트리는 바퀴의 회전량을 이용하여 로봇의 이동 거리와 위치를 추정하는 기술입니다.

실습에서는 바퀴 미끄러짐과 마모에 따른 오차 누적 현상을 확인합니다.

이를 통해 오도메트리만으로는 정확한 위치추정에 한계가 있으며, 추가 센서를 활용한 위치 보정이 필요하다는 점을 학습합니다.

<a name="notion-heading-423d9e129df780eea29cd41be0efba5f"></a>

### 📄 4-3. PID 제어 실습

PID 제어를 활용하여 로봇이 제자리에서 목표 각도인 90°만큼 회전하도록 구현합니다.

Kp, Ki, Kd 값을 변경하면서 다음 현상을 확인합니다.

- 제어 응답 속도 변화
- 목표 각도를 초과하는 오버슈트
- 목표 지점에 도달한 후 남는 정상상태 오차

<a name="notion-heading-423d9e129df780668ca8ce9bd8dd5618"></a>

### 📄 4-4. 경로탐색 알고리즘 비교

창고 지도에서 출발지와 목적지를 설정하고 Dijkstra와 A* 알고리즘을 비교합니다.

- Dijkstra: 출발지를 기준으로 주변 노드를 고르게 탐색합니다.
- A*: 목표 지점까지의 예상 거리를 활용하여 목표 방향으로 탐색합니다.

실습 결과 두 알고리즘 모두 동일한 최단 거리인 29.2m의 경로를 찾았으며, A*는 탐색한 영역을 줄여 더 효율적으로 경로를 계산했습니다.

## 📕 5. Physical AI와 최신 로봇 AI 기술

<a name="notion-heading-423d9e129df7806d8019d2ec3ce1df66"></a>

### 📄 5-1. 파운데이션 모델(Foundation Model)

파운데이션 모델은 대규모 데이터를 이용하여 사전 학습한 뒤 다양한 작업에 활용하는 모델입니다.

로보틱스 분야에서는 시각 정보를 이해하고, 언어를 해석하며, 실제 행동까지 수행하는 방향으로 발전하고 있습니다.

<a name="notion-heading-423d9e129df7801aa8a6cc08e2e524d5"></a>

### 📄 5-2. Physical AI와 시뮬레이션

Physical AI는 물리적인 환경을 이해하고 실제 행동을 수행하는 AI 기술입니다.

실제 로봇만으로 학습 데이터를 수집하면 시간과 비용이 많이 들고 안전 문제도 발생할 수 있습니다.

따라서 시뮬레이터를 활용하여 대량의 합성 데이터를 생성하고 학습 및 검증에 활용합니다.

<a name="notion-heading-423d9e129df780bfbeaff6c2789f0209"></a>

### 📄 5-3. NVIDIA Cosmos와 World Foundation Model

NVIDIA Cosmos는 물리적 환경을 이해하고 예측하는 월드 파운데이션 모델과 관련된 기술입니다.

월드 모델은 현재 장면을 바탕으로 이후에 발생할 상황을 예측하거나 생성하는 데 활용됩니다.

대표적인 활용 방향은 다음과 같습니다.

- Transfer: 시뮬레이션 데이터를 다양한 환경으로 확장합니다.
- Predict: 행동 수행 이후의 결과를 예측합니다.
- Reason: 영상 속 상황을 물리적 맥락에서 이해합니다.

<a name="notion-heading-423d9e129df780d1b451cb254e56b058"></a>

### 📄 5-4. LLM · VLM · RAG · VLA

로봇과 AI 모델의 상호작용을 위한 주요 기술입니다.

- LLM: 언어를 이해하고 작업을 단계별로 구성합니다.
- VLM: 언어와 영상 정보를 함께 이해합니다.
- RAG: 외부 문서와 정보를 검색하여 응답에 활용합니다.
- VLA: 영상과 언어를 바탕으로 로봇의 행동을 생성합니다.

## 📕 6. NVIDIA Isaac ROS와 NITROS

<a name="notion-heading-423d9e129df7800fbbe8f7fb1f5e4f17"></a>

### 📄 6-1. NVIDIA Isaac

NVIDIA Isaac은 로봇 개발을 위한 CUDA 가속 라이브러리, 애플리케이션 프레임워크 및 AI 모델을 포함하는 기술 생태계입니다.

대표적인 구성요소는 다음과 같습니다.

- Isaac Sim: 로봇 시뮬레이션
- Isaac Lab: 로봇 학습 및 강화학습
- Isaac ROS: CUDA 가속 ROS 2 패키지
- Cosmos: 월드 파운데이션 모델
- GR00T: 휴머노이드 로봇 관련 파운데이션 모델

<a name="notion-heading-423d9e129df7807cb709d72f178ee527"></a>

### 📄 6-2. ROS 2란?

ROS 2는 로봇 애플리케이션 개발을 위한 오픈소스 프레임워크입니다.

운영체제 자체가 아니라 로봇의 여러 기능과 프로세스가 통신할 수 있도록 지원하는 미들웨어입니다.

대표적인 패키지에는 다음이 있습니다.

- Nav2: 이동로봇 내비게이션
- MoveIt: 로봇팔의 경로계획 및 모션 계획

<a name="notion-heading-423d9e129df7803293d1cd1cd4947c7e"></a>

### 📄 6-3. Isaac ROS란?

Isaac ROS는 NVIDIA의 GPU 가속 기술을 활용하는 ROS 2 패키지 및 AI 모델 모음입니다.

기존 ROS 2 생태계와 호환되며, 로봇의 인지 및 센서 데이터 처리 등을 가속할 수 있습니다.

<a name="notion-heading-423d9e129df780acb5d9c805f5b6ed08"></a>

### 📄 6-4. NITROS란?

NITROS(NVIDIA Isaac Transport for ROS)는 ROS 2 노드 간 데이터 전달 과정에서 불필요한 CPU와 GPU 메모리 복사를 줄이는 기술입니다.

주요 기능은 다음과 같습니다.

- Type Adaptation: GPU 버퍼 등 가속기에 적합한 데이터 형식을 활용합니다.
- Type Negotiation: 노드 간 지원하는 데이터 형식을 협의하여 적절한 전달 방식을 선택합니다.

이를 통해 대용량 영상이나 점군 데이터를 효율적으로 처리하면서 기존 ROS 2 도구와의 호환성을 유지할 수 있습니다.

## 📕 7. 실습환경 구축 및 동작 점검

<a name="notion-heading-423d9e129df780a99222eb88b77a9c15"></a>

### 📄 7-1. Ubuntu 및 개발 도구 설치

Ubuntu 24.04 환경을 구축하고 기본 개발 도구를 설치합니다.

- Terminator: 터미널 관리 및 분할 실행
- Google Chrome: 개발 문서 및 웹 자료 확인
- VS Code: Python 코드 작성 및 실행
- Slack: 교육 관련 공지 및 커뮤니케이션

<a name="notion-heading-423d9e129df780478ebfe788e950b608"></a>

### 📄 7-2. NVIDIA DLI Workspace 구성

`~/nvidia_dli`를 기준으로 실습 파일과 설치 프로그램을 관리합니다.

- downloads: 다운로드 파일 관리
- venv: Python 가상환경
- isaacsim: Isaac Sim 5.1
- IsaacSim-ros_workspaces: ROS 2 예제 워크스페이스
- day01/labs: 1일차 실습 파일
- work: 개인 작업 결과물

<a name="notion-heading-423d9e129df78041b6e8dc200c2855c8"></a>

### 📄 7-3. Isaac Sim 및 ROS 2 연동 확인

Isaac Sim 5.1에서 Nova Carter 창고 시뮬레이션을 실행하고 ROS 2와의 데이터 연동을 확인합니다.

- Isaac Sim에서 로봇 및 창고 환경 실행
- ROS 2 Topic을 통한 센서 데이터 확인
- `/clock`, `/cmd_vel` 등 주요 토픽 확인
- Nav2 및 RViz를 활용한 위치추정과 경로계획 확인
- 목표 지점을 설정하여 시뮬레이션 로봇의 자율주행 확인

이를 통해 시뮬레이터 안의 로봇이 실제 로봇처럼 ROS 2 메시지를 주고받으며 동작하는 과정을 학습합니다.
